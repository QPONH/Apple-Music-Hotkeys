MusicFloat v14.35 —— Apple Music 歌词浮窗 + 全局快捷键
（Apple-Music-Hotkeys 修改版）

使用方法
1. 把压缩包完整解压到任意文件夹。
2. 直接运行 MusicFloat.exe（单文件，自带 .NET 运行时，不需要另外安装）。
3. 启动后出现设置窗口（或已按设置隐藏到托盘）；在设置里勾选“启用”并点“应用”即可显示歌词浮窗。

本版相对 14.34 的变化
· 2×2 排版：**下一句也改成格内居中**（横竖都居中），不再贴着底边；
  当前句仍是左上格内居中、超过一格高向右换列。每句最多占半窗高。
· 长单词不再缩小字号：词格按单词的真实宽度排版，所在列跟着加宽；
  排版容器从 Grid 换成 Canvas——Grid 会在格子边界把超出的内容裁掉，
  于是长词正好在中线被切断。现在长词可以越过格子、伸进空的相邻格，
  既保持原字号又不会被切，也不会盖住别的字。
  注意：如果单词本身比整个浮窗还宽（26 号字下大约 13 个字母以上），
  仍然会在窗口边缘被裁掉——这是“不缩字号”本身的上限。

上一版（14.34）的内容仍然有效
· 英文（按单词换行）排布不变；中英混排超过一半是英文时按右对齐单词竖排。
· 关闭「半透明背景」时浮窗不接管鼠标，点击穿透到下面的窗口。
· 「无法连接歌词服务器」自动重试：5s → 10s → 20s → 30s → 每 60s；手动重查立刻执行。
· 纯音乐等只有一句的歌词：靠右、垂直居中。
· 14.31：歌名+艺人双重校验；切歌艺人串错自动重查；缓存带版本号。
· 14.30：作词/作曲不再当歌词；无底板时文字带描边；离屏位置回中间；退出不报错。

歌词浮窗操作
· 右键菜单（需开启背景）：打开设置 / 重新查找歌词 / 退出 MusicFloat。
· 开启背景后可直接拖动窗口；拖边缘可调整大小（位置尺寸会自动保存）。
· 设置里可调整字号、颜色、透明度、横排/竖排、歌词偏移等。
· 每次查询会在 crash.log 记一行
  “LyricsResult: 歌名 | 艺人 | Found/NotFound/Unavailable | 行数”。
