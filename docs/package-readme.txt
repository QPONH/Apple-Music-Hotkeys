MusicFloat v14.36 —— Apple Music 歌词浮窗 + 全局快捷键
（Apple-Music-Hotkeys 修改版）

使用方法
1. 把压缩包完整解压到任意文件夹。
2. 直接运行 MusicFloat.exe（单文件，自带 .NET 运行时，不需要另外安装）。
3. 启动后出现设置窗口（或已按设置隐藏到托盘）；在设置里勾选“启用”并点“应用”即可显示歌词浮窗。

本版相对 14.35 的变化
新功能（来自 startup-fix 版本）
· 修复开机启动：启动时按保存的设置重新同步注册项（路径变化/丢失/被 Windows 启动应用禁用都能修复），
  注册表不可用时回退到当前用户“启动”文件夹快捷方式；关闭时一并清理。
· 歌词翻译：设置里可开启翻译、单独设置翻译字号、颜色与摆放位置（来源提供 tlyric 时生效）。
· 配色与排版选项：当前句/下一句颜色；单词类与非单词文字分别可选“上下排列 / 对角 / 固定靠右”。
· 下一句模式：正常显示 / 隐藏 / 用当前句翻译占位。
· 设置页统一滚动；关闭下拉菜单时滚轮滚动页面而不是误改选项。
· 快捷键：别名写法（Ctrl+Esc 与 Control+Escape）识别为重复；低级键盘钩子不再漏出连发的按下事件；
  注册失败回滚已应用设置并保留草稿。
· 切换到下一首前会按专辑曲序预取下一首歌词（尽力而为，拿不到队列时不影响正常查询）。

审查并修复的问题
· 项目原本无法编译：StartupService 使用了 System.IO 却没有 using。
· 每 0.25 秒强制置顶会盖住开始菜单 / Alt-Tab（绕过 14.35 的 shell 判断）。
· 关闭浮窗时窗口位置保存无效（已改为在 Closing 时保存），最后一次拖动/缩放不丢。
· 每次启动/每次点“应用”都会重写开机启动注册项，可能覆盖用户在 Windows 里手动禁用的状态；
  现在只有设置与实际注册状态不一致时才同步。
· 四宫格里较宽的翻译文本会被窗口右边缘裁掉。
· iTunes 预取用严格相等匹配当前曲目，常常匹配不到，预取形同虚设（改为与艺人/专辑一致的包含匹配）。
· 艺人变体在艺人为空时重复添加空串，导致重复请求。
· 网络失败耗尽重试后被显示成“本地歌曲 无歌词”，改成“未找到歌词”。
· 删除无用的分支与重复状态判断（设计不变）：水平单词分支里恒为假的翻译判断、窗口侧重复的预取去重、
  重试条件里重复的上下限、StartupService 的重复路径解析与四段重复清理代码。

14.35 及更早的要点
· 2×2 排版：当前句左上格内居中、下一句右下格内居中；长单词保持字号，越过格子也不会被裁。
· 关闭「半透明背景」时浮窗不接管鼠标（点击穿透）。
· 歌词匹配：歌名 + 艺人双重校验；切歌艺人串错自动重查；本地缓存带版本号。
· 连接失败自动重试（初次 + 3 次，15 秒内）；纯音乐等单句歌词靠右垂直居中。
· 作词/作曲等制作信息不再当作歌词；无底板时文字带描边；浮窗离屏时回到屏幕中央。

歌词浮窗操作
· 右键菜单（需开启背景）：打开设置 / 重新查找歌词 / 退出 MusicFloat。
· 开启背景后可直接拖动窗口；拖边缘可调整大小（位置尺寸会自动保存）。
· 每次查询会在 crash.log 记一行
  “LyricsResult: 歌名 | 艺人 | Found/NotFound/Unavailable | 行数”。
