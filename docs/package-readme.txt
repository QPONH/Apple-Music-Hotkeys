MusicFloat v14.33 —— Apple Music 歌词浮窗 + 全局快捷键
（Apple-Music-Hotkeys 修改版）

使用方法
1. 把压缩包完整解压到任意文件夹。
2. 直接运行 MusicFloat.exe（单文件，自带 .NET 运行时，不需要另外安装）。
3. 启动后出现设置窗口（或已按设置隐藏到托盘）；在设置里勾选“启用”并点“应用”即可显示歌词浮窗。

本版相对 14.32 的变化
· 关闭「半透明背景」时，浮窗**不再接管鼠标**：点击会穿到下面的窗口
  （连歌词文字上也能点穿），拖动、右键菜单也随之关闭——这时请用托盘菜单或设置窗口操作。
  打开背景时一切照旧：可以拖动、右键出菜单。

上一版（14.32）的内容仍然有效
· 「无法连接歌词服务器」自动重试：5s → 10s → 20s → 30s → 每 60s 一次；手动重查会立刻执行。
· 酷狗搜索关键词去掉 “艺人 — 专辑 - Single” 的专辑部分；网易云/酷狗优先用拆分后的艺人。
· 纯音乐等只有一句的歌词：靠右、垂直居中；英文单句缩到一行内。
· 14.31：匹配更严格（歌名+艺人），切歌艺人串错自动重查；
· 14.30：作词/作曲不再当歌词；无底板时文字带描边；离屏位置回中间；退出不报错；
  每次查询在 crash.log 记一行 “LyricsResult: 歌名 | 艺人 | 状态 | 行数”。

歌词浮窗操作
· 右键菜单（需开启背景）：打开设置 / 重新查找歌词 / 退出 MusicFloat。
· 开启背景后可直接拖动窗口；拖边缘可调整大小（位置尺寸会自动保存）。
· 设置里可调整字号、颜色、透明度、横排/竖排、歌词偏移等。
