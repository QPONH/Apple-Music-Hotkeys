## 一、概述
**文档信息**

| 版本号 | 日期 | 作者 |
|---|---|---|

### 1. 需求背景
- **目标用户现状**：用户在 Windows 上使用 Edge 浏览器中的 Apple Music PWA 听歌，同时进行 FH6 游戏或工作。切歌后需要知道当前歌曲，但不想切出游戏或打开播放器窗口。
- **核心痛点**：系统媒体提示和播放器 UI 不够贴合游戏/工作场景；现有开源参考项目机制可用，但视觉样式、动效质感和 Apple 风格不足。
- **当前问题汇总**

| 问题点 | 问题描述 | 当前影响 |
|---|---|---|
| 切歌反馈弱 | 游戏或全屏工作中不方便确认当前播放歌曲 | 需要切屏或忍受信息缺失 |
| 视觉不统一 | 参考项目 UI 更像工具/HUD，不像 Apple 原生系统提示 | 影响长期使用的审美体验 |
| 控制入口分散 | 播放/暂停、上一首、下一首、喜欢等操作需要回到播放器或记系统快捷键 | 操作打断当前场景 |
| 风险边界需明确 | 游戏注入、DX hook、驱动 overlay 风险高且不轻量 | 与免费开源本地工具定位冲突 |

### 2. 需求目标
- **产品目标**
  - 提供一个免费开源、本地运行、无账号的 Windows 轻量覆盖层工具。
  - 在切歌时以默认 A「极简封面浮标」显示封面，可选显示歌名/歌手。
  - 逐步支持键盘、Xbox 手柄、DS5 手柄快捷键绑定。
- **成功标准**

| 指标 | 当前状态 | 目标状态 |
|---|---|---|
| Apple Music PWA 歌曲读取 | 未实现 | 可通过 SMTC 读取歌名、歌手、封面 |
| 覆盖层显示 | 未实现 | 可在桌面、工作窗口、FH6 无边框/普通全屏场景中置顶显示 |
| 资源占用 | 未实现 | 隐藏状态无动画负担，仅保留低频监听/事件订阅 |
| 风险边界 | 口头确认 | 明确不做游戏注入、DX hook、驱动 overlay |

### 3. 需求范围
- **包含**
  - Edge Apple Music PWA 的 SMTC 歌曲信息读取。
  - Win32 透明、置顶、点击穿透悬浮窗。
  - A/B/C 三种显示样式：默认 A 极简封面浮标，B 液态玻璃控制条，C 沉浸封面卡片。
  - 歌名、歌手、基础按钮显示开关。
  - 键盘快捷键绑定；Xbox、DS5 手柄快捷键作为分阶段能力。
  - 本地 JSON 设置保存、托盘常驻、预览测试。
- **不包含**
  - 游戏注入、DirectX hook、驱动 overlay、反作弊绕过。
  - 多音乐平台深度适配。
  - 复杂歌词、频谱、社交分享、账号系统、云同步。

## 四、功能说明

### 功能 1：SMTC 读取 Apple Music PWA
**功能描述**  
用户启动 Apple Music PWA 并播放歌曲后，应用通过 Windows SMTC 获取当前歌曲信息，解决游戏/工作中无法直接看到歌曲的问题。

**用户流程**
```text
启动应用
  -> 后台请求 SMTC 当前会话
  -> 读取媒体属性和封面
  ├─ 成功 -> 更新主设置页状态，切歌时触发 Overlay
  ├─ 失败：无媒体会话 -> 显示“请先在 Apple Music 中播放歌曲”
  └─ 失败：封面为空 -> 使用占位封面，继续显示歌名/歌手
```

**状态机**
| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 未检测 | 启动后无 SMTC 会话 | 检测到有效会话 | 主设置页提示未检测到播放 |
| 已连接 | SMTC 返回歌名 | 会话消失或播放源变化 | 显示当前歌曲信息 |
| 封面待刷新 | 歌曲变化但封面为空或疑似旧封面 | 刷新成功或超时 | 先显示文字/占位，稍后补封面 |
| 不支持 | Windows 版本或 API 不可用 | 环境变化后重试 | 提示当前系统不支持 SMTC |

**字段规范**  
本功能无用户输入字段。

**文案规范**
| 场景 | 文案内容 |
|---|---|
| 空状态 | 请先在 Apple Music 中播放一首歌曲 |
| 加载中 | 正在读取系统媒体会话... |
| 操作成功 | 已连接 Apple Music |
| 操作失败 | 未读取到媒体会话 |
| 权限不足 | 当前环境无法访问系统媒体会话 |
| 网络异常 | 本功能不依赖网络；请检查 Apple Music 是否正在播放 |

**异常处理**
| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 无媒体会话 | SMTC 当前会话为空 | 保持后台低频重试 | 请先在 Apple Music 中播放一首歌曲 |
| 元数据为空 | 歌名为空 | 不显示 Overlay | 未读取到歌曲名称 |
| 封面缺失 | Thumbnail 为空或读取失败 | 使用本地渐变占位图 | 不弹错误，仅显示占位封面 |
| API 不支持 | 系统版本低或 API 异常 | 禁用媒体功能 | 当前系统不支持 SMTC |

### 功能 2：Overlay 显示与样式
**功能描述**  
用户可在主设置页选择 A/B/C 显示样式。默认 A 为极简封面浮标，切歌时短暂显示，不抢焦点、不接收鼠标点击。

**用户流程**
```text
检测到歌曲变化
  -> 判断 Overlay 是否暂停
  -> 读取当前样式配置
  -> 显示 Overlay 3-5 秒
  ├─ 成功 -> 自动淡出/缩放隐藏
  ├─ 失败：封面为空 -> 显示占位封面
  └─ 失败：动画不可用 -> 直接显示静态 Overlay
```

**状态机**
| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 隐藏 | 无歌曲变化或显示结束 | 歌曲变化/测试显示 | 屏幕无 Overlay |
| 入场 | 歌曲变化触发 | 动画结束 | 封面淡入、轻微缩放/位移 |
| 展示 | 入场结束 | 展示时长结束或新歌触发 | A/B/C 当前样式 |
| 出场 | 展示时长结束 | 动画结束 | 淡出并隐藏窗口 |
| 暂停 | 用户暂停覆盖层 | 用户恢复 | 不显示切歌提示 |

**字段规范**
| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| 显示样式 | 枚举 | 是 | A/B/C | 只能选择预置样式 | 请选择显示样式 |
| 显示时长 | 数字 | 是 | 1-10 秒 | 默认 5 秒，范围 1-10 | 显示时长需在 1-10 秒之间 |
| 位置 X/Y | 数字 | 是 | 0-100% | 默认左侧中下，范围 0-100 | 位置需在屏幕范围内 |
| 缩放 | 数字 | 是 | 70-180% | 默认 100% | 缩放需在 70%-180% 之间 |
| 显示歌名 | 布尔 | 是 | 无 | 默认开启 | 无 |
| 显示歌手 | 布尔 | 是 | 无 | 默认开启 | 无 |
| 显示按钮 | 布尔 | 是 | 无 | A 默认关闭，B/C 可开启 | 无 |

**文案规范**
| 场景 | 文案内容 |
|---|---|
| 空状态 | 当前没有可预览的歌曲，已使用示例封面 |
| 加载中 | 正在准备覆盖层... |
| 操作成功 | 覆盖层设置已保存 |
| 操作失败 | 覆盖层显示失败，请重试 |
| 权限不足 | 无法创建置顶窗口，请尝试重新启动应用 |
| 网络异常 | 本功能不依赖网络 |

**异常处理**
| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 置顶失败 | Win32 窗口样式设置失败 | 保持普通窗口并记录诊断 | 覆盖层置顶失败 |
| 多屏位置越界 | 显示器变化后坐标失效 | 自动夹取到主屏幕可见范围 | 已自动调整覆盖层位置 |
| 动画卡顿 | 帧率或系统负载异常 | 降级为淡入淡出 | 已降低动效以保持流畅 |
| 游戏独占全屏不可见 | 游戏绕过 DWM 合成 | 不做注入和 hook | 当前全屏模式可能无法显示覆盖层 |

### 功能 3：快捷键与输入绑定
**功能描述**  
用户可分阶段绑定键盘、Xbox、DS5 输入，触发播放/暂停、上一首、下一首、喜欢、测试显示等动作。

**用户流程**
```text
打开快捷键页
  -> 选择动作
  -> 点击绑定输入
  -> 按下键盘或手柄组合
  ├─ 成功 -> 保存并注册快捷键
  ├─ 失败：快捷键冲突 -> 提示更换组合
  ├─ 失败：设备未连接 -> 保留原绑定
  └─ 失败：DS5 当前不可读 -> 提示暂不可用
```

**状态机**
| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 未绑定 | 动作无快捷键 | 捕获成功 | 显示“未设置” |
| 等待输入 | 用户点击绑定 | 捕获成功/取消/超时 | 输入框高亮，提示按下组合键 |
| 已绑定 | 快捷键注册成功 | 用户重新绑定或清除 | 显示组合键文本 |
| 冲突 | 注册失败或组合重复 | 用户换键 | 显示冲突提示 |
| 设备不可用 | 手柄未连接或驱动不可读 | 设备可用 | 显示设备状态 |

**字段规范**
| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| 动作 | 枚举 | 是 | 无 | 播放/暂停、上一首、下一首、喜欢、测试显示 | 请选择动作 |
| 键盘快捷键 | 文本 | 否 | 32 字符 | 支持 Ctrl/Alt/Shift/Win + 主键 | 快捷键格式无效 |
| Xbox 快捷键 | 文本 | 否 | 32 字符 | 支持 A/B/X/Y/LB/RB/LT/RT/DPad/Start/Back 组合 | Xbox 组合键格式无效 |
| DS5 快捷键 | 文本 | 否 | 32 字符 | 建议默认值：L1/R1/L2/R2/DPad/Options/Create 组合 | DS5 组合键格式无效 |
| 启用设备 | 布尔 | 是 | 无 | 各设备独立开关 | 无 |

**文案规范**
| 场景 | 文案内容 |
|---|---|
| 空状态 | 选择一个动作后开始绑定快捷键 |
| 加载中 | 正在等待输入... |
| 操作成功 | 快捷键已保存 |
| 操作失败 | 快捷键注册失败，请换一组组合键 |
| 权限不足 | 当前快捷键可能被其他应用占用 |
| 网络异常 | 本功能不依赖网络 |

**异常处理**
| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 键盘热键占用 | RegisterHotKey 返回失败 | 不覆盖原配置 | 此快捷键已被占用 |
| Xbox 未连接 | 读取不到 XInput 设备 | 保持 Xbox 功能关闭 | 未检测到 Xbox 手柄 |
| DS5 未连接 | 读取不到 DS5 设备 | 保持 DS5 功能关闭 | 未检测到 DS5 手柄 |
| 喜欢动作不可用 | Apple Music PWA 无通用 SMTC 喜欢接口 | 禁用或标注实验功能 | 喜欢功能需要单独适配 Apple Music |

### 功能 4：托盘常驻与本地设置
**功能描述**  
应用后台常驻托盘，用户可快速打开设置、暂停覆盖层、测试显示或退出。所有配置保存在本地 JSON。

**用户流程**
```text
启动应用
  -> 加载本地配置
  -> 初始化托盘和后台服务
  ├─ 成功 -> 后台等待歌曲变化
  ├─ 配置损坏 -> 使用默认配置并备份旧文件
  └─ 用户退出 -> 停止监听并关闭 Overlay
```

**状态机**
| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 前台设置 | 打开设置窗口 | 关闭/最小化 | 显示主设置页 |
| 托盘后台 | 关闭或最小化窗口 | 双击托盘 | 只显示托盘图标 |
| 覆盖层暂停 | 用户选择暂停 | 用户恢复 | 托盘菜单显示已暂停 |
| 退出 | 用户选择退出 | 无 | 程序关闭 |

**字段规范**
| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| 开机自启 | 布尔 | 是 | 无 | 默认关闭 | 无 |
| 关闭到托盘 | 布尔 | 是 | 无 | 默认开启 | 无 |
| 配置文件路径 | 系统生成 | 是 | 无 | `%LOCALAPPDATA%/AppleMusicOverlay/settings.json` | 配置保存失败 |

**文案规范**
| 场景 | 文案内容 |
|---|---|
| 空状态 | 暂无设置，请使用默认配置开始 |
| 加载中 | 正在加载设置... |
| 操作成功 | 设置已保存 |
| 操作失败 | 设置保存失败 |
| 权限不足 | 无法写入本地配置目录 |
| 网络异常 | 本工具为本地应用，不需要联网 |

**异常处理**
| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 配置文件损坏 | JSON 解析失败 | 备份损坏文件，加载默认值 | 配置已重置为默认值 |
| 写入失败 | 本地目录无权限 | 保持内存设置并提示 | 设置保存失败，请检查权限 |
| 托盘不可用 | 系统托盘初始化失败 | 保持窗口模式运行 | 托盘初始化失败 |

## 五、技术与实现约束
- 技术基线：.NET 8 Windows 桌面应用，优先 WPF + Win32 窗口样式；后续如有必要再评估 WinUI 3。
- 媒体读取：优先使用 Windows.Media.Control 的 SMTC，不登录 Apple 账号，不调用 Apple 私有接口。
- 覆盖层：只使用透明置顶窗口、点击穿透、不抢焦点；不做游戏注入、DX hook、驱动 overlay。
- 资源策略：隐藏状态停止 UI 动画；手柄轮询仅在启用对应设备时开启；媒体读取事件优先，低频兜底。
- 开源策略：免费开源，本地配置，不收集用户数据。
