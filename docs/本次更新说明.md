# 本次更新说明：快速重试、歌词缓存与下一曲预取

## 已修改

- 歌词服务器连接异常时，初次查找后最多自动重试 3 次。
- 每次歌词查询最多运行约 3.25 秒，重试间隔约 200 毫秒，重试流程整体限制在 15 秒内；超时后不再无限显示查找状态。
- 连接异常的中间状态仍只显示“正在查找歌词……”，重试耗尽后显示“本地歌曲 无歌词”。
- 修复歌词缓存写盘时机：缓存快照在防抖等待后生成，并加锁读取，减少连续切歌时新歌词未写入缓存的情况。
- 当前歌曲有歌词、且播放接近结束时，尝试从公开曲目目录定位同专辑曲序中的下一首，并提前查找/缓存它的歌词。缓存会保存到应用设置目录的 `lyrics-cache.json`，下次遇到相同曲目时可直接使用。

## 下一曲预取的限制

Windows 的 Global System Media Transport Controls（SMTC）提供的是当前媒体项目，并不提供 Apple Music 的实际“接下来播放”队列。因此，此版本只能在歌曲的专辑元数据可匹配时，按同专辑曲序预取下一首；随机播放、歌单跨专辑播放、单曲播放或本地上传歌曲无法保证预测准确。预取结果只写入对应歌曲的缓存，不会直接覆盖当前显示的歌词；新曲目仍按自己的标题和歌手匹配。
