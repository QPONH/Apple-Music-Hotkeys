# 本次更新说明

## 本轮代码审查与修复
- 手动重新查找歌词时，若当前缓存项已删除，会立即安排缓存文件更新，避免旧歌词在重启后重新载入。
- 切歌或关闭悬浮歌词窗口时取消进行中的歌词请求；取消操作不会被误判为网络故障，也不会覆盖新歌曲结果。
- 翻译时间戳匹配由逐行重复排序改为线性扫描，降低长歌词在 UI 线程上的处理耗时。
- 读取歌词缓存时过滤空文本、无效时间戳和异常条目，并按时间排序，降低损坏/旧缓存引发崩溃或错序的风险。
- 字号和透明度输入支持当前区域设置的小数格式，并避免显示设置时把小数值四舍五入成整数。
- 颜色输入解析对格式错误做安全处理；音量会话访问异常写入日志而不是无声失败。
- 修复同一快捷键用不同别名表达时未识别重复的问题；读取到重复快捷键配置时跳过后续冲突项并提示，而不是让音量快捷键只有其中一个动作生效。
- 快捷键捕获失败时恢复到捕获前的草稿配置，而不是错误回滚到上一次保存的配置；快捷键服务发生异常时写日志并安全处理。
- 快捷键重注册失败时回滚已应用设置对象，保留用户尚未应用的草稿，避免配置状态出现“UI 显示一套、运行中使用另一套”。
- 修复低级键盘钩子只拦截第一次按键、自动重复按下事件泄漏到前台程序的问题。
- 开机恢复播放流程中若取消操作，确保 Alt 键与鼠标左键在 finally 中释放，避免按键/鼠标状态残留。
- 开机启动配置会比较当前程序路径，避免程序移动后留下指向旧路径的启动项；注册表访问失败会返回明确错误。
- 应用设置后保留快捷键注册警告，不再被“设置已应用并保存”覆盖。

## 统一设置页滚动
- 移除“悬浮歌词”大卡片内部带固定高度的独立滚动区域，展开显示基础显示、横排、竖排、下一句与翻译、颜色与外观等全部设置。
- 歌词设置内容改由当前页最外层的统一滚动条滚动，不再需要在卡片内部寻找第二条滚动条。
- 保留各设置项原有的宽度自适应、分组小标题、下拉菜单滚动和颜色/字号等功能。

## 下拉选项滚轮行为
- 下拉菜单关闭时，滚轮不再直接切换 ComboBox 当前选项，即使控件刚刚获得过焦点也不会意外改值。
- 关闭状态下滚轮转交给外层页面滚动区域，继续滚动设置内容。
- 只有主动打开下拉菜单后，滚轮才用于浏览/切换菜单选项。

## 验证情况
- 进行 XAML XML 解析、XAML 事件处理器名称检查、C# 词法括号配对检查和 ZIP 完整性检查。
- 保留悬浮歌词内部无独立滚动条、关闭下拉菜单时滚轮交给外层页面的行为。
- 当前环境没有可用的 .NET SDK，无法在此处完成编译、单元测试或 Windows 实际界面测试；发布前仍需在 Windows/.NET 8 SDK 环境中构建与运行验证。

## 代码精简与重复逻辑收敛
- 将歌词启用、关闭到托盘、启动时隐藏、开机启动和开机恢复播放等复选框，合并到一个有白名单映射的事件处理器。
- 将默认歌词色、当前句颜色、下一句颜色统一使用一套颜色校验/提交流程，保留各自的配置字段与默认颜色样式。
- 合并开机恢复播放等待秒数和坐标的输入归一化逻辑，让失焦提交和点击“应用”走同一实现，并保留两种场景原本不同的无效输入回退值。
- 将快捷键设置读写、显示标签和冲突提示标签集中到快捷键元数据表，消除多处相互重复的动作映射；删除未被调用的旧设置读取方法。
- 将 LRCLIB、网易云和酷狗歌词候选项共有的标题/艺人匹配与评分收敛到公共函数，评分阈值与优先级保持不变。
- 将竖排单词格和字符格重复的固定高度、换行、透明度与对齐设置收敛到共用方法。
- 删除未被调用的歌词时长距离辅助函数。
- C# 源码总行数从 6,429 行降至 6,346 行，减少 83 行（约 1.3%）；主要是消除重复实现，而不是通过删除功能或仅压缩空白来降低行数。
