# MusicFloat - Apple Music Hotkeys 修改版

基于 [MusicFloat](https://github.com/Adudumax/MusicFloat) 修改，为 Windows 版 Apple Music 提供全局快捷键及额外功能。

## 保留功能

- 设置窗口
- 全局上一曲 / 下一曲 / 播放暂停快捷键
- 系统托盘
- 设置窗口可选择：关闭时隐藏到托盘 / 启动时自动隐藏

## 新增功能

- 全局 Apple Music 音量快捷键（每次调整 ±5%）
- Windows 开机自启动
- 启动时自动播放原有待播列表
- 悬浮歌词

## 已移除功能

- 游戏手柄控制
- 收藏功能
- 网易云音乐联动

## 使用说明

- 点击快捷键输入框后，直接按下需要的组合键即可重新定义快捷键；松开主键后自动保存。
- 音量控制针对 Windows 音量混合器中的 Apple Music 音频会话，不改变系统总音量。
